# Aula 03 • Consumindo APIs com JavaScript puro (GET)

Projeto da aula de **Interação com APIs** — SESI SENAI.

## Rodar
1. Abra a pasta no **VS Code** (extensão *Live Server*).
2. Botão direito em `index.html` → **Open with Live Server**.
3. Escreva seu código em `api.js`.

Os exercícios estão em [`Lista_Exercicios_Pratica_JS_Aula03.md`](Lista_Exercicios_Pratica_JS_Aula03.md).

## Estrutura
- `index.html` — tela pronta (cards, campos e botões com `id`)
- `api.js` — **você programa aqui**
- `api/` — dados locais da fábrica SENAI (`./api/ordens.json`)

Teste URLs sem Postman: barra do navegador ou https://hoppscotch.io
